# GuessQuest

Guess the computer's number from 1 to 20. In this individual take-home, you'll get the game building, bring two features together through pull requests, and add one improvement of your own.

**Time:** about 6½ hours. **Setup:** Ubuntu or another Linux distribution, a C++17 compiler, CMake 3.16+, Git, and a GitHub account.

The starter build is intentionally broken. Begin with the [assignment](docs/assignment.md). Each part points to a short reading. If you get stuck after trying an idea, open one [hint](docs/hints.md) at a time.
